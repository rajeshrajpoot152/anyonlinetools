## 2. Special Formatting Modifiers

Free Fire supports BBCode-style formatting tags combined with color brackets:
- `[b]` = **Bold Text** (e.g. `[b][FF0000]BOSS`)
- `[i]` = *Italic Text* (e.g. `[i][00FF00]Slayer`)
- `[c]` = Centered Text (for profile bio / signature banner)
- `[s]` = ~~Strikethrough~~
- `[u]` = <u>Underline</u>
